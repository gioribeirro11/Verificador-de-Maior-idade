# Verificador de Maioridade

Programa em Python que pergunta a idade do usuário e informa se ele é maior ou menor de idade.

## Como funciona

1. O usuário digita a idade.
2. Se a idade for **18 ou mais**, o programa informa que a pessoa é maior de idade.
3. Caso contrário, informa que é menor de idade.

## Requisitos

- Python 3.6 ou superior

## Como executar

```bash
python Verificador_de_Maioridade.py
```

## Exemplo de uso

```
qual é sua idade 20
Você é maior de idade
```

```
qual é sua idade 15
você é menor de idade
```

## Conceitos praticados

- Entrada de dados com `input()`
- Conversão para inteiro com `int()`
- Operadores de comparação (`>=`)
- Estrutura condicional `if` / `else`
